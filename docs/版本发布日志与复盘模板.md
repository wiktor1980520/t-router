# TRouter 版本发布日志与复盘模板

## 1. 文档目的

本模板用于规范 TRouter 后续版本发布说明、上线记录和版本复盘，避免每次发版都依赖临时沟通或零散记录。

目标是让每个版本都能回答清楚：

- 这次发了什么
- 为什么发
- 影响了谁
- 上线后结果如何
- 哪些经验要保留

---

## 2. 使用方式

建议每个正式版本都配套两类记录：

- 发布日志
- 发布后复盘

推荐文件命名方式：

- `release-v1.0.0.md`
- `postmortem-v1.0.0.md`

如果是小版本，可以合并成一份文档。

## 18. 推荐执行建议

TRouter 后续每个重要版本都建议至少做三件事：

- 发布前有清晰变更说明
- 发布后有明确验证动作
- 发布完成后有一份简短复盘

这样文档会逐渐沉淀成真正的版本资产，而不是一次性记录。
